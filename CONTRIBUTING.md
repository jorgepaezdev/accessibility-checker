# Contributing

Thanks for your interest in **accessibility-checker**.

## What we accept

- **Bug reports** via [GitHub Issues](https://github.com/jorgepaezdev/accessibility-checker/issues/new?template=bug_report.yml) — any GitHub user can open one.

## What we do not accept

- **Code contributions** (pull requests, patches, or direct pushes from outside collaborators).

External pull requests are closed automatically. Please file an issue instead.

## Using the code

The repository is **public**. Anyone can:

- Clone it over HTTPS/SSH
- Download a ZIP from the repo page (**Code → Download ZIP**)
- Browse the source on GitHub

Only the maintainers can change the code on this repository.
